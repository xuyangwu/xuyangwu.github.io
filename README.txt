MINIMAL THREE-PAGE WEBSITE

Pages:
- index.html: minimal homepage
- research.html: research topics and related papers
- publications.html: complete publication list by year

Homepage style:
- no header
- no navigation bar
- simple bulleted Research links
- a single Publications link
- grey email text
- no cards, icons, arrows, or separators inside the Research list

All publication years are collapsed by default.

Deployment:
Copy all files and the assets folder to the root of your GitHub Pages repository.
