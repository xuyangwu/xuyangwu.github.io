FINAL WEBSITE STRUCTURE

Main page:
- Personal information
- Email
- Six clickable research topics
- Complete publication list by year
- Every year is collapsed by default, including 2026

Navigation:
- None (clean header only)

Files:
- index.html
- six research-topic HTML pages
- site.css
- site.js
- assets/self.png

Before deployment:
1. Add your CV PDF to this folder and name it cv.pdf.
2. Copy all files and the assets folder to the root of your GitHub Pages repository.
3. Commit and push.

No jemdoc, npm, Bootstrap, Tailwind, or build process is required.
